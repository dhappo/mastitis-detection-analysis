# Data folder

The raw dataset is **not included** in this repository. Download it from its original Kaggle page (add the link here) and save it as:

```
data/cow_milk_mastitis_dataset.csv
```

Expected columns: `Cow_ID`, `Day`, `Milk_Temperature`, `Milk_pH`, `Milk_Conductivity`, `Somatic_Cell_Count`, `Milk_Yield`, `Clotting`, `class1` (800 rows, one per cow). Please check the dataset page for its current licence and citation requirements before reusing it.
